## Stop conditions and scope

- A `completed/PASS` model report is evidence of that bounded run, not proof that a different model, Host version, device or workspace is supported. Validate file bytes and raw records independently.
- The current Windows private kit is the nearest useful deliverable. There is no justified percentage or calendar date for general release until Level A rollback and Level B packaging gates are closed.
- Do not repeat a full live acceptance suite for every official Host release. Maintain exact pins and run the risk-based compatibility gate; promote only a tested exact combination.
- No formal D2 attempt, daily switch, public publication, credential transfer, Home overwrite or cleanup of dirty worktrees is implied by this plan.
