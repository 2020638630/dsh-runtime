## 当前架构边界

DSH Runtime 是独立 Runtime Kernel，不依赖：

- `ai-app`
- `backend`
- `delta-pipeline`
- Codex CLI
- CodeBuddy CLI
- PostgreSQL
- Ollama
- GPU / RAG / MCP

未来方向：

```text
DSH Runtime
    -> Capability Providers
        -> ai-app
        -> Codex CLI
        -> CodeBuddy CLI
        -> MCP
        -> future capabilities
```

核心原则：

- DSH owns the loop.
- Plugins are bounded execution units.
- Everything below DSH is bounded.
- Do not abstract before evidence.
- Local LLM is optional.
